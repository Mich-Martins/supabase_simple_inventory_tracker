# Simple Inventory Tracker

## Overview

A beginner-friendly database project built with Supabase
and PostgreSQL.

## Objectives

- Create a PostgreSQL table.
- Insert and retrieve inventory records.
- Calculate total inventory value.
- Identify products with low stock.
- Practise SQL and version control.

## Technologies

- Supabase
- PostgreSQL
- SQL
- Visual Studio Code
- GitHub

## Project Structure

- sql/01_create_tables.sql: Creates the products table.
- sql/02_insert_sample_data.sql: Inserts sample products.
- sql/03_analysis_queries.sql: Contains inventory analysis queries.

## How to Use

1. Create a Supabase project.
2. Run 01_create_tables.sql.
3. Run 02_insert_sample_data.sql.
4. Run queries from 03_analysis_queries.sql.

## Notes

The project uses sample inventory data.
No database credentials are included in this repository.
